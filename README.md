### 💡 About This Presentation
This repository contains the standalone, lightweight HTML/CSS/JS slide deck built to pitch and present the **SmartHealth AI** project—a voice-first, gender-responsive clinical assistant designed for underserved women across Sub-Saharan Africa.

### 📱 Features
- **Touch & Tablet First:** Fluid swipe gesture navigation (`←` / `→`), tap controls, and dynamic viewport scaling (`100dvh`).
- **Interactive Workflows:** Clickable operational pipeline tracing data through Ear (STT), Brain (LLM), Tools (RAG/SQL), and Voice (TTS).
- **Zero Build Tooling:** Pure vanilla HTML, CSS, and modern JavaScript ready for instant, static deployment on Vercel.
